Smart Login System

An AI-powered secure login system with anomaly detection and a futuristic galactic UI.

![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Python](https://img.shields.io/badge/Python-3.8%2B-blue)

---

## ✨ Features

- **Password Hashing** using Werkzeug (Secure)
- **AI-based Anomaly Detection** using Isolation Forest
- **Adaptive Authentication** – OTP required for suspicious logins
- **Login History** with IP Address tracking
- **Futuristic Galactic UI** with neon effects
- **Session Management** & Flash Messages
- **Responsive Design**
