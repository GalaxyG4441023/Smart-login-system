How to Run This Project
Follow these simple steps to run the project on your laptop:
1. Clone the Repository
Bashgit clone
           
           https://github.com/GalaxyG4441023/smart-login-system.git 
After copying the project file
in the powershell type 
          cd smart-login-system
3. Create Virtual Environment
Bashpython
         -m venv venv
5. Activate Virtual Environment
For Windows:
PowerShell
       venv\Scripts\activate
4. Install Required Packages
Run this command to install all necessary packages:
Bashpip
       install Flask Werkzeug numpy scikit-learn
6. Run the Project
Bashpython
       app.py
   For closing
        ctrl+C
   for Deactivativating Virtual environment
          powershell
                 deactivate
(if installing the packages showing some issue)
